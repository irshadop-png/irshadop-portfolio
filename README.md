# IRSHAD OP — Creative Portfolio

This repository publishes the portfolio through GitHub Pages.

## Publish the portfolio
1. Download the `IRSHAD-OP-PORTFOLIO-UPLOAD.zip` package prepared for this repository.
2. Upload that ZIP file to the repository root and name it exactly `portfolio-upload.zip`.
3. Commit the upload to the `main` branch.
4. The GitHub Actions workflow extracts the website and deploys it to GitHub Pages.

The deployment workflow is in `.github/workflows/deploy-pages.yml`.
